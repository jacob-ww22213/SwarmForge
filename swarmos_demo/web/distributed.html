SwarmOS Distributed Controller

多机小模型网络控制台

这是一个可展示的多机 AI 协作 Demo。controller 维护在线节点，按任务做 MoE 稀疏路由，再执行两轮 MoA 协作，把每个节点的输出、耗时、评分和最终聚合结果直接展示出来。

1. 节点上线 worker 心跳注册模型、角色和地址
2. MoE 路由 controller 选出第一轮 proposal workers
3. MoA 复审 第二轮 review workers 基于上一轮结果继续精炼
4. 结果评测 展示耗时、完成率、风险、满意度和历史记录

演示建议

先启动 2 到 3 个 worker，再点击下面的样例任务按钮，把任务填入输入框后直接运行。
